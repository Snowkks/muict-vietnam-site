MUICT VIETNAM WEBSITE - SINGLE-PAGE EDITION

Extract the ZIP and open index.html. No installation or build is needed.

One page with a section menu: Programme, Specialisations, Tuition, How to apply, Life in Thailand, Questions, Contact.
All information is on the page. The only external link is the "Open the online application" button.

Edit index.html for content and style.css for appearance.
app.js runs the mobile menu and marks each admission round Closed / Open now / Opens soon from today's date.
To change round dates, edit the data-s (start) and data-e (end) attributes on the table rows.

This is a student recruitment campaign concept, not an official Mahidol admissions site.
